# Tifa Rejoin updates

This repository distributes compiled Android APKs and update metadata only. Application source is private.

Download the latest APK from the Releases page. Install over the existing app to preserve your settings. Android may ask you to allow installation from this source.

Once the updater-enabled build is installed, use Check for app updates inside Tifa Rejoin for future updates.

Download **Tifa-Rejoin.apk** from the [latest release](https://github.com/DarkBotGen/tifa-reconnect-updates/releases/latest/download/Tifa-Rejoin.apk). The identical Tifa-Reconnect.apk asset and this repository URL are retained for compatibility with older installed updaters.
