# Tifa Rejoin — Android and PC

## Downloads

Open the **[latest release](https://github.com/DarkBotGen/tifa-reconnect-updates/releases/latest)**.
Its two uploaded assets are:

- **Tifa-Rejoin.apk** — Android.
- **Tifa-Rejoin-PC EXE** — Windows PC.

Both editions use the same owner-issued Tifa username and password. One phone and
one PC require two available device slots. Successful first activation is saved
locally. The PC Donations page is removed.

Install the Android APK over the existing app to preserve settings and activation.
Older Android updaters that require a release-attached `update.json` need one manual
installation of the current APK; future checks read `main/update.json` in this repo.

This is a **binary downloads and update-metadata repository**. No application source,
signing keys, credentials, or account data are published here. GitHub's automatic
"Source code" archives contain only this downloads repository's README/metadata,
not the Android or PC application code.

Tifa Rejoin PC is derived from Evanovar RAM under GPL-3.0. License and author notices
are bundled in the EXE; corresponding PC source/build scripts are available from
the maintainer on request, outside the public release asset list.
